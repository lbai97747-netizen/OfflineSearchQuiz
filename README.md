# 离线搜题

拍照 / 选图 → 本地离线 OCR（Google ML Kit 中文）→ 在本地题库里模糊匹配 → 显示答案。
识别和匹配全部在手机上完成，不联网。

## 打包 APK（不用装 Android Studio）

1. 在 GitHub 新建一个仓库（私有也行）。
2. 把本文件夹里的所有内容（包括隐藏的 `.github` 文件夹）上传到仓库根目录。
3. 打开仓库的 Actions 页面，等 "Build APK" 跑完（约 3~6 分钟）。
4. 点进这次运行，在 Artifacts 里下载 `app-debug-apk`，解压得到 `app-debug.apk`，传到手机安装。

如果你想本地打包：用 Android Studio 打开本文件夹，菜单 Build → Build APK(s)。

## 题库格式

UTF-8 编码的 JSON 数组，每项两个字段：

```json
[
  {"question": "中国的首都是哪里？", "answer": "北京"},
  {"question": "水的化学式是什么？", "answer": "H2O"}
]
```

在 App 里点「上传题库」选这个文件，导入后会保存在手机里，下次打开还在。

## 匹配说明

- 忽略标点、空白和换行；综合题干字符覆盖率、二元组相似度与编辑距离，容忍少量 OCR 错字。
- 会尝试在 OCR 结果中匹配题干长度附近的文本片段，降低题号、选项和页面杂字的干扰。
- 仅返回题库中已有的题目和答案，不调用云端、不生成或推理新答案。
- 匹配度低于 68% 时显示“题库中没有找到足够匹配的题目”，不提供答案；最多显示 3 个候选。
- 识别出的文字会填到输入框，可以手动修正后再点「搜索」。

> 提醒：模糊匹配阈值是保守过滤，不代表数学意义上的准确率；题库内容和 OCR 清晰度会影响结果。
